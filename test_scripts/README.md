# Тестовые скрипты для API

Эта папка содержит скрипты для тестирования всех эндпоинтов API.

## Использование

Убедитесь, что сервер запущен на `http://localhost:8081` перед запуском тестов.

### Быстрый тест всех эндпоинтов

```bash
./test_all.sh
```

### Индивидуальные тесты

#### 1. Расклады рун (Divination)
```bash
./test_runes.sh
```

#### 2. Сонник (Sonnik)
```bash
./test_sonnik.sh
```

#### 3. Совместимость (Compatibility)
```bash
./test_compatibility.sh
```

#### 4. Таро - основной расклад (Tarot)
```bash
./test_tarot.sh
```

#### 5. Таро - продолжение расклада (с историей)
```bash
./test_tarot_followup.sh
```

#### 6. Таро - первое продолжение (только основной расклад в истории)
```bash
./test_tarot_followup_first.sh
```

#### 7. Таро (упрощенный вариант)
```bash
./test_tarot_simple.sh
```

#### 8. Таро (с английскими картами)
```bash
./test_tarot_english.sh
```

## Зависимости

Для красивого форматирования JSON ответов требуется `jq`:
```bash
# macOS
brew install jq

# Linux (Ubuntu/Debian)
sudo apt-get install jq
```

Если `jq` не установлен, можно убрать `| jq '.'` из скриптов.

## Порты

Все скрипты настроены на порт `8081` (локальная разработка).
Для продакшн сервера измените порт в скриптах на `8080`.
